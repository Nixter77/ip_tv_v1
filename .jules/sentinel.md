## 2025-05-15 - Enhanced URL Masking and Search DoS Protection
**Vulnerability:** Information leakage through unmasked path-based tokens in URLs and potential DoS through excessively long search queries.
**Learning:** IPTV URLs often embed tokens in path segments (e.g., `/key=value/`) or use hybrid structures. Standard URL parsing can fail due to unencoded spaces, requiring a robust pre-encoding step that MUST preserve `?` and `#` to maintain structural integrity for subsequent masking.
**Prevention:** Always mask path segments containing `=` unconditionally. Implement length limits on user-controlled `@Published` properties that trigger expensive filtering or indexing operations. Use fail-secure regex fallbacks to redact sensitive parameter values (`token`, `key`, `auth`, etc.) if structured parsing fails.
